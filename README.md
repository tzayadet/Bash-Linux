Repositorio de prácticas pequeñas de terminal y scripting. Incluye un ejemplo inicial de salida por consola.

## Contenido

- `EchoHello.sh`: ejemplo mínimo de script Bash.

## Ejecución

En Linux o macOS:

```bash
chmod +x EchoHello.sh
./EchoHello.sh
```

También puede ejecutarse con:

```bash
bash EchoHello.sh
```

## Tecnologías

- Bash
